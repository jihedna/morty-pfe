# Use Cases

## Client journey

1. A visitor browses properties, registers, and logs in.
2. The client creates a search request with property type, budget, location, size, urgency, and notes.
3. The system calculates a lead score and ranks compatible agents with an explanation of each match.
4. The client reviews matching properties/agents, favorites listings, or saves a reusable search.
5. The client starts a conversation or books a property appointment.
6. The client follows notifications, appointment status, and any contract/deal linked to the selected property.

## Property decision support

1. An authenticated user explores property and market maps.
2. A client requests personalized recommendations based on profile interactions.
3. The client estimates a sale/rent price or enters financing assumptions for an investment score.
4. The UI presents estimates, ranges, score components, methodology notes, and risks; results are advisory.

## Agent workflow

1. An agent maintains availability, territories, property types, and budget range.
2. The agent creates and updates listings, images, features, and publication state.
3. The agent reviews ranked leads, compatibility and conversion scores, then accepts or updates lead status.
4. The agent handles client messages, appointments, and notifications from one workspace.

## Manager workflow

1. A manager activates/deactivates users and maintains agent records.
2. The manager oversees listings, appointments, conversations, contracts, market areas, and chatbot articles.
3. The manager reviews KPIs, funnels, time series, regional heat maps, and model metadata.

## Assistant workflow

An authenticated user asks a market, property, agent, appointment, investment, listing, status, or general question. The assistant classifies the intent, searches active knowledge articles, responds with available citations and suggested actions, and uses a safe fallback when the knowledge base has no adequate answer.
